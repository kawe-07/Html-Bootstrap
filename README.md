# GT3 Racing

Projeto acadêmico desenvolvido utilizando HTML, CSS e Bootstrap.

# Sobre o projeto

O site apresenta informações sobre a categoria GT3 do automobilismo, incluindo:
- História da categoria
- Principais pilotos
- Carros GT3
- Competições
- Circuitos históricos
  
## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
